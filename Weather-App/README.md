# Weather App (HTML, CSS, JavaScript)

A responsive Weather Application built using **JavaScript**, **HTML5**, and **CSS3**, integrated with the **OpenWeatherMap API** to fetch real-time weather data based on user input.

---

## Features

- Search weather by city name
- Real-time API integration using Fetch API
- Displays:
  - Current Temperature
  - Weather Description
  - Feels Like Temperature
  - Humidity
  - Wind Speed
- Dynamic Weather Icon rendering
- Clean and responsive UI design

---

## Technologies Used

- HTML5
- CSS3 (Flexbox, responsive layout, styling)
- JavaScript
- Fetch API
- Async / Await
- OpenWeatherMap API

---

## Project Structure

- `index.html` – Application layout and structure
- `style.css` – UI styling and responsive design
- `script.js` – Application logic and API integration
- `config.js` – API key configuration (excluded via .gitignore)

---

## How It Works

1. User enters a city name.
2. The form submission triggers an API request using Fetch.
3. Weather data is retrieved asynchronously.
4. DOM elements are dynamically updated with:
   - Temperature
   - Description
   - Weather icon
   - Additional weather details
